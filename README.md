# 🌸 Iris SVM Classifier - Machine Learning & Web App

Dự án gồm **2 phiên bản**:
1. **Phiên bản Giao Diện Web React Hiện Đại (Chính)**: Là giao diện bạn thấy trực tiếp trên bản Preview của Google AI Studio với Cổng Đăng Nhập/Đăng Ký, 7 phân hệ MLOps chuyên sâu (Dự đoán, Ranh giới 2D kèm Support Vectors viền vàng, Báo cáo hiệu năng 98%, AutoML kéo thả file, FastAPI Swagger UI, v.v.).
2. **Phiên bản Python Streamlit (app.py)**: Phiên bản Python chạy bằng Streamlit trên cổng 8501.

---

## 🌟 Cách 1: Chạy Giao Diện Web React Hiện Đại (Khuyến Nghị - Giống hệt 100% bản Preview)

Giao diện đầy đủ tính năng: Đăng nhập/Đăng ký, 7 Tab MLOps, hiệu ứng pháo hoa Confetti, biểu đồ Canvas 2D & Spider Radar, v.v.

### Bước 1: Cài đặt thư viện Node.js
Mở Terminal trong VS Code và chạy:
```bash
npm install
```

### Bước 2: Khởi động máy chủ
```bash
npm run dev
```

### Bước 3: Mở trình duyệt
Truy cập vào địa chỉ:
👉 **`http://localhost:3000`** (hoặc `http://localhost:5173`)

---

## 🐍 Cách 2: Chạy Bản Python Streamlit (app.py)

Nếu bạn muốn chạy bản mã nguồn Python thuần:

### Bước 1: Cài đặt thư viện Python
```bash
pip install -r requirements.txt
```

### Bước 2: Khởi chạy Streamlit
```bash
streamlit run app.py
```

### Bước 3: Mở trình duyệt
Trình duyệt sẽ mở tại địa chỉ:
👉 **`http://localhost:8501`**
